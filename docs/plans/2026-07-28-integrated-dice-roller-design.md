# Integrated Dice Roller — Design

## Context

All roll dispatch in the character sheet goes through `window.Roll20Bridge.sendToRoll20(rollData)` in `roll20-bridge.js`. Currently that function logs the formula string + label to the roll log panel and forwards the formula to Roll20 via Beyond20 (or clipboard fallback). Dice are always evaluated by Roll20; the app never sees individual die values.

This feature adds a toggleable "Integrated" mode where the app evaluates rolls client-side, displays individual die values in the roll log panel, and detects crits (doubles on kept d10s). Roll20 still receives the formula in the normal way — two sources of truth, but the in-app panel gives instant feedback including crit callout.

## 1. Toggle

A "🎲 Integrated / 📤 Roll20" button added to `.top-bar-actions` in `index.html` (right side of the header, next to Export/Import). Preference stored in `localStorage` as key `ttrpg_roll_mode` with values `'integrated'` or `'roll20'` (default `'roll20'`). Two new functions on `window.Roll20Bridge`:

- `getRollMode()` — returns `'integrated'` | `'roll20'`
- `setRollMode(mode)` — writes to localStorage and updates the button label

The toggle button calls `Roll20Bridge.setRollMode()` and updates its own text. No page reload needed. Global, not per-character.

## 2. Formula evaluator in `dice.js`

New exported function `evaluateFormula(formula)`. Handles all formula shapes currently generated by this codebase:

| Formula shape | Example |
|---|---|
| `XdY` | `2d10`, `1d10`, `1d1` |
| `XdYkhZ` | `4d10kh2` (advantage) |
| `XdYklZ` | `4d10kl2` (disadvantage) |
| `XdY + N` | `2d10 + 5` |
| `XdY - N` | `2d10 - 3` |
| Weapon damage | `1d8`, `2d6 + 4`, `1d12` |

Returns:
```js
{
  dice:      number[],   // all raw die rolls
  kept:      number[],   // dice kept after kh/kl filter
  dropped:   number[],   // dice excluded by kh/kl
  modifier:  number,     // flat +/- value
  total:     number,     // sum(kept) + modifier
  isDoubles: boolean     // kept.length >= 2 && all kept values equal
}
```

`isDoubles` is true whenever all kept dice show the same face value and there are at least 2 kept dice. No roll-type filtering — applies to any 2d10 roll (attacks, tests, skills, saves all use 2d10).

## 3. Roll log enhancement

`roll20-bridge.js` stores the evaluated result when integrated mode is on:

- `_logRoll(rollData)` calls `evaluateFormula(rollData.formula)` in integrated mode and stores `{label, formula, evalResult}` instead of just `{label, formula}`
- `_renderRollLog()` branches on `getRollMode()`:
  - **Roll20 mode**: unchanged — shows `formula | label` (current behavior)
  - **Integrated mode**: shows die faces as `.die-box` chips (kept bright, dropped dimmed), modifier, `= total`, and if `isDoubles`: a gold `⚡ CRIT!` span

The roll is still forwarded to Roll20 via the existing Beyond20 / clipboard path in all modes.

## 4. New CSS in `style.css`

```css
.die-box       — small square chip displaying a single die value
.die-kept      — bright variant (white text, solid border)
.die-dropped   — dimmed variant (muted text, dashed border, strikethrough optional)
.roll-crit     — gold text "⚡ CRIT!" callout
.roll-total    — bold total display
```

## Files changed

| File | Change |
|---|---|
| `dice.js` | Add `evaluateFormula(formula)` + export |
| `roll20-bridge.js` | Add `getRollMode`/`setRollMode`; enhance `_logRoll`/`_renderRollLog` for integrated mode |
| `style.css` | Add `.die-box`, `.die-kept`, `.die-dropped`, `.roll-crit`, `.roll-total` |
| `index.html` | Add roll-mode toggle button to `.top-bar-actions` |

No changes to `app.js` — all call sites already route through `Roll20Bridge.sendToRoll20`.

## Non-goals

- No dice animation
- No per-character roll history
- No separate modal for roll results (inline in existing roll log panel)
- No change to Roll20 message format (formula still sent, not pre-evaluated result)
